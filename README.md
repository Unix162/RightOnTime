# RightOnTime

מערכת לניהול משימות אישיות במסגרת עבודת הגשה בקורס TypeScript.

## תיאור הפרויקט

המערכת מאפשרת למשתמש לנהל את המשימות שלו ולעקוב אחר ביצוען.
המשימות נשמרות ב-LocalStorage ולכן נשארות גם לאחר רענון הדף.

## פונקציונליות

- הוספה, עריכה ומחיקה של משימות.
- סימון משימות כהושלמו.
- סינון משימות לפי סטטוס.
- חיפוש לפי שם או תיאור המשימה.
- הגדרת רמת עדיפות ותאריך יעד.
- שמירת משימות ב-LocalStorage.
- הצגת סטטיסטיקה ואחוז השלמת המשימות.
- הצגת ציטוטי השראה באמצעות API חיצוני.
- התאמת התצוגה למסכים בגדלים שונים.

## טכנולוגיות

- React
- TypeScript
- Vite
- CSS
- LocalStorage
- Fetch API

## API

לקבלת ציטוטי השראה נעשה שימוש ב-Quotable API.
במקרה שהשירות אינו זמין, מתבצעת פנייה ל-DummyJSON.
אם שני השירותים אינם זמינים, מוצגת הודעת שגיאה.

## מבנה הפרויקט

- components - קומפוננטות של ממשק המשתמש.
- types - הגדרת ממשקים וטיפוסים.
- services - תקשורת עם API חיצוני.
- App.tsx - הלוגיקה הראשית של האפליקציה.
- App.css - עיצוב האפליקציה.

## התקנה והרצה

יש לוודא שמותקנים Node.js בגרסה 22.12 ומעלה ו-npm.

התקנת התלויות:

```bash
npm install
```

הרצת הפרויקט:

```bash
npm run dev
```

בניית הפרויקט:

```bash
npm run build
```

בדיקת הקוד:

```bash
npm run lint
```
