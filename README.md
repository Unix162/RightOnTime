# RightOnTime

מערכת לניהול משימות אישיות שפותחה במסגרת עבודת הגשה בקורס TypeScript.

## תיאור הפרויקט

מטרת הפרויקט היא לאפשר למשתמש לנהל את המשימות שלו,
לקבוע סדרי עדיפויות ותאריכי יעד ולעקוב אחר התקדמותו.

המערכת בנויה כאפליקציית דף יחיד (SPA) באמצעות React,
TypeScript ו-Vite, ללא צורך בשרת או במסד נתונים חיצוני.

## יכולות המערכת

- הוספת משימה עם שם ותיאור אופציונלי.
- עריכת משימות קיימות.
- סימון משימה כהושלמה וביטול השלמתה.
- מחיקת משימה לאחר אישור המשתמש.
- סינון משימות לפי סטטוס השלמה.
- חיפוש משימות לפי שם או תיאור.
- הגדרת רמת עדיפות ותאריך יעד.
- שמירה אוטומטית של המשימות ב-LocalStorage.
- הצגת ציטוטי השראה באמצעות API חיצוני.
- הצגת סטטיסטיקה ומד התקדמות.
- התאמת התצוגה למסכים בגדלים שונים.

## הסבר על אופן פעולת המערכת

### ניהול משימות

רשימת המשימות מנוהלת בקובץ App.tsx באמצעות useState.
כל שינוי ברשימת המשימות גורם לעדכון התצוגה.

הפעולות המרכזיות בקובץ:

- addTask - יצירת משימה חדשה והוספתה למערך המשימות.
  לכל משימה נוצר מזהה ייחודי באמצעות crypto.randomUUID.

- toggleTask - איתור משימה לפי המזהה שלה ושינוי
  הערך של completed.

- deleteTask - מחיקת משימה מהמערך באמצעות filter,
  לאחר קבלת אישור מהמשתמש.

- editTask - עדכון פרטי משימה באמצעות map,
  תוך שמירה על המזהה, תאריך היצירה וסטטוס ההשלמה שלה.

- getFilteredTasks - החזרת רשימת המשימות בהתאם
  לסינון ולטקסט החיפוש שהמשתמש הזין.

### הוספת משימה ועריכתה

הקומפוננטה TaskForm אחראית על קבלת פרטי המשימה
מהמשתמש באמצעות טופס.

ערכי השדות נשמרים באמצעות useState.
לפני שליחת הטופס מתבצעת בדיקה ששם המשימה אינו ריק.

לאחר הוספת המשימה שדות הטופס מתאפסים.

הקומפוננטה TaskItem אחראית על הצגת משימה בודדת
ומאפשרת לערוך את פרטיה, למחוק אותה או לשנות את
סטטוס ההשלמה שלה.

במצב עריכה, פרטי המשימה נשמרים במשתנים זמניים
עד שהמשתמש מאשר את השינויים.

### סינון וחיפוש

הקומפוננטה TaskFilter מאפשרת לבחור בין שלוש אפשרויות:

- כל המשימות.
- משימות שהושלמו.
- משימות שטרם הושלמו.

הקומפוננטה TaskSearch מאפשרת לחפש משימות לפי
שם המשימה או התיאור שלה.

החיפוש מתבצע באמצעות includes ו-toLowerCase,
כך שניתן לחפש גם חלק ממילה וללא תלות באותיות
גדולות או קטנות באנגלית.

ניתן לשלב בין החיפוש לבין הסינון.
פעולות אלו משפיעות על התצוגה בלבד ואינן משנות
את מערך המשימות המקורי.

### שמירת נתונים ב-LocalStorage

המערכת משתמשת בשני useEffect לצורך טעינה ושמירה
של המשימות באחסון המקומי של הדפדפן.

בעת טעינת האתר מתבצעת קריאה מהאחסון באמצעות
localStorage.getItem והמרת הנתונים באמצעות JSON.parse.

בכל שינוי ברשימת המשימות מתבצעת המרה למחרוזת
באמצעות JSON.stringify ושמירה באמצעות localStorage.setItem.

המשתנה isLoaded משמש למניעת שמירה לפני סיום
טעינת המשימות הקיימות.

מפתח האחסון הוא:

rightontime-tasks

הנתונים נשמרים באופן מקומי בדפדפן ולכן ניתן
להמשיך לעבוד עם המשימות גם לאחר רענון הדף.

### שימוש ב-API חיצוני

הקובץ quoteService.ts אחראי על קבלת ציטוטים
באמצעות Fetch API.

השירות הראשי הוא Quotable:

https://api.quotable.io/quotes/random?tags=inspirational

במקרה של תקלה או חוסר זמינות של Quotable,
מתבצעת פנייה לשירות חלופי בשם DummyJSON:

https://dummyjson.com/quotes/random

הפונקציה fetchQuote מבצעת את הבקשות באמצעות
async/await ובודקת את תקינות תשובת השרת.

זמן ההמתנה לכל בקשה מוגבל לחמש שניות.

הקומפוננטה QuoteBox אחראית על הצגת הציטוט,
שם המחבר, מצב הטעינה והודעות שגיאה.

ניתן לקבל ציטוט חדש באמצעות לחיצה על הכפתור
"הצג ציטוט חדש".

אם שני השירותים אינם זמינים, מוצגת הודעת שגיאה
והמשתמש יכול להמשיך לנהל את המשימות שלו.

### סטטיסטיקה ומד התקדמות

הקומפוננטה TaskStats מקבלת את מערך המשימות
ומחשבת את הנתונים הבאים:

- מספר המשימות הכולל.
- מספר המשימות שהושלמו.
- מספר המשימות שנותרו.
- אחוז השלמת המשימות.

אחוז ההשלמה מחושב באמצעות חלוקת מספר המשימות
שהושלמו במספר המשימות הכולל והכפלה ב-100.

כאשר אין משימות, אחוז ההתקדמות הוא 0
כדי למנוע חלוקה באפס.

### שימוש ב-TypeScript

בפרויקט הוגדרו מספר ממשקים וטיפוסים:

- TaskInput - פרטי המשימה שהמשתמש מזין.
- Task - מבנה משימה מלאה במערכת.
- TaskPriority - רמות העדיפות האפשריות.
- TaskFilter - אפשרויות הסינון.
- Quote - מבנה הנתונים של ציטוט.
- DummyQuote - מבנה התשובה של שירות הציטוטים החלופי.

בנוסף, הוגדרו ממשקים עבור ה-Props של הקומפוננטות
וטיפוסים עבור משתנים, פונקציות וערכים מוחזרים.

הקוד נמנע משימוש מפורש בטיפוס any.

### עיצוב

עיצוב המערכת בוצע באמצעות CSS.

משימות שהושלמו מוצגות בצבע ירוק ועם קו חוצה
על שם המשימה.

רמות העדיפות מוצגות בצבעים שונים בהתאם לחשיבותן.

באמצעות Media Queries בוצעה התאמה של ממשק
המשתמש גם למסכים קטנים.

## התקנה והרצה

יש לוודא שמותקנים Node.js ו-npm.
מומלץ להשתמש ב-Node.js בגרסה 22.12 ומעלה,
התואמת לדרישות Vite בפרויקט.

התקנת התלויות:

```bash
npm install
```

הרצת הפרויקט:

```bash
npm run dev
```

לאחר ההרצה יש לפתוח את הכתובת המוצגת בטרמינל.

בניית הפרויקט:

```bash
npm run build
```

הפעלת גרסת ההפצה לאחר ביצוע Build:

```bash
npm run preview
```

בדיקת איכות הקוד:

```bash
npm run lint
```

## בדיקות

במהלך הפיתוח בוצעו בדיקות להוספה, עריכה, מחיקה,
השלמה, סינון וחיפוש של משימות.

בנוסף נבדקה שמירת המשימות לאחר רענון הדף
והצגת ציטוטים באמצעות API חיצוני.

בניית הפרויקט באמצעות npm run build הסתיימה
בהצלחה וללא שגיאות.

קיימת אזהרה אחת הקשורה לעדכון State מתוך useEffect
בעת טעינת הנתונים מ-LocalStorage.
